# 🛡️ Bug Bounty Intelligence Portal: Local Edition

This is the high-performance local version of the Bug Bounty Recon Portal. It is configured for **MAX POWER** execution, bypassing all cloud memory limits.

## 🚀 Quick Start
1. **Prerequisites**: Ensure you have [Python 3.x](https://www.python.org/) installed.
2. **Install Requirements**:
   ```bash
   pip install flask
   ```
3. **Launch the Portal**:
   ```bash
   python server.py
   ```
4. **Access**: Open your browser to `http://localhost:5000`

## 🛠️ Included Toolchain (Full Power)
The system is pre-loaded with the following 7 tools in the `/bin` directory:
- **Subfinder / Assetfinder / Amass**: Subdomain Intelligence
- **DNSX**: Active Resolution
- **Httpx**: Tech Stack & Title Fingerprinting
- **Naabu**: Tactical Port Scanning (Top 1000)
- **Katana**: Deep Web Crawling (Depth-2)

## 📊 Intelligence Dossiers
All scan results are saved in:
- `recon_storage/`: Full Markdown reports and raw JSON data.
- `dashboard_data.js`: Live stats for the UI.

## 🛡️ Support
- **Full Power Mode**: This version uses 50 threads and 15 workers for maximum speed.
- **Refresh-Proof**: If you refresh during a scan, use the **MISSION RE-ATTACHMENT** prompt to resume.
